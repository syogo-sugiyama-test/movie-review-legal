1. 運営者と問い合わせ先

2. 取得する情報と利用目的

取得する情報 取得の方法 利用目的

通報の内容（通報した人、対象、理由） ユーザーが通報時に入力 不適切な投稿・ユーザーへの対応（モデレーション）

3. 外部サービスの利用と情報の提供

本アプリは、運営のために次の外部サービスを利用します。利用目的の範囲で、必要な情報がこれらのサービスに送られます。

サービス 提供元 送られる情報 目的
Amazon Web Services（Cognito、Lambda、DynamoDB、CloudFront、CloudWatch、SNS など） Amazon Web Services, Inc. / アマゾン ウェブ サービス ジャパン合同会社 第 2 項に記載した情報のすべて 認証、データの保存、API の提供、ログ・監視。保存先は東京リージョン（ap-northeast-1）です
The Movie Database（TMDb） TMDb 映画の検索語、閲覧した映画の ID（運営者のサーバーを経由して取得します）。映画ポスターの画像は、アプリが TMDb の配信サーバーから直接取得するため、その際に端末の IP アドレスが TMDb に届きます 映画情報・画像の表示
Firebase Cloud Messaging（FCM）/ Apple Push Notification service Google LLC / Apple Inc. 端末識別用のトークン プッシュ通知の配信基盤（現時点では送信なし）
  • 本アプリは TMDb の API を利用していますが、TMDb による推奨や認定を受けたものではありません。
  • 法令に基づく場合、または人の生命・身体・財産の保護のために必要な場合を除き、ユーザーの個人情報を、ユーザーの同意なく第三者へ提供しません。

4. 他のユーザーへの公開範囲

  • 表示名、プロフィールアイコン、好きなジャンル、投稿したレビューは、他のユーザーに公開されます。メールアドレスは公開されません。
  • ブロックしたユーザー、およびブロックされたユーザーとの間では、お互いのプロフィールとレビューが表示されなくなります。

5. 保存期間と削除

  • アカウントの情報は、ユーザーが退会するまで保存します。
  • 退会（設定画面の「退会」）をすると、 レビュー、フォロー・ブロック、プロフィール、端末トークン、認証情報を削除します。
  • ただし、通報の記録は、不正利用の防止とモデレーションの記録のため、削除せずに残します。通報した人の識別情報は、退会時に匿名化します。通報の記録は、不要になった時点で削除します。
  • 端末トークンは、最後の更新から 90 日で自動的に削除されます。
  • サーバーのログ（クラッシュ報告を含む）は、14 日で自動的に削除されます。ログにはログイン中のユーザー ID が含まれ、退会した場合も、期限（14 日）まで残ります。
  • アプリを使わずに削除を依頼する場合は、アカウント削除のご案内ページ、または第 1 項の問い合わせ先をご利用ください。

6. 安全管理

  • 通信は暗号化（HTTPS）されます。パスワードは認証基盤が暗号化して管理します。
  • アクセスできる権限は、運営者に限定し、多要素認証で保護します。
  • 万一、情報の漏えいが起きた場合は、法令に従い、速やかに通知します。

7. ユーザーの権利

ユーザーは、自分の個人情報について、開示、訂正、利用停止、削除を求めることができます。プロフィールの編集と退会はアプリ内で行えます。それ以外のご請求は、第 1 項の問い合わせ先へご連絡ください。ご本人であることを確認のうえ、合理的な期間内に対応します。

8. 子どもの利用

本アプリは、13 歳未満の方を対象としていません。13 歳未満の方の個人情報を意図的に取得することはありません。

9. 改定

本ポリシーを改定する場合は、アプリ内または公開ページで通知します。重要な変更の場合は、アプリ内で改めて同意をお願いすることがあります。

10. 準拠法

本ポリシーは日本法に準拠します。
